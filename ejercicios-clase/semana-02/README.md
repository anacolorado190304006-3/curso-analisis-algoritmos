# Entorno de trabajo — Python

Proyecto desarrollado con **Python 3.14.7**, usando **WSL Ubuntu**, `pyenv` y un entorno virtual `venv`.

### Configuración

**Crear el entorno:**

```bash
python -m venv .venv
```

**Activarlo:**

```bash
source .venv/bin/activate
```

**Instalar dependencias:**

```bash
python -m pip install -r requirements.txt
```

Para reproducir el entorno, se requiere Python 3.14.7 y ejecutar los comandos anteriores. El directorio `.venv` no debe subirse al repositorio.
